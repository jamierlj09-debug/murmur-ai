# Murmur AI

A responsive one-page landing page for a fictional small AI brand. Built with plain HTML, embedded CSS and JavaScript; no build tools or external dependencies.

## Live site
https://jamierlj09-debug.github.io/murmur-ai/

## Features
- Dark forest-green and lime design with an abstract CSS orb
- Mobile-friendly layout, keyboard focus styles, skip link and reduced-motion support
- Three switchable, explicitly prewritten demo responses
- No AI API, signup form, payment system or tracking scripts

## Edit and publish
Edit `index.html` on the `main` branch. GitHub Pages serves from the repository root and rebuilds after commits. Open `index.html` in a browser to preview locally.

Murmur AI is a placeholder brand concept, not a claim about an existing business or a functioning AI product. Replace the branding and sample copy with your own details before using it to represent a real company. A real chatbot needs a separate secure backend; never place secret API keys in this public repository.
